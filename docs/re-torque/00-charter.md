# Charter: Torque
Date: 2026-10-19

| Item | Value |
|---|---|
| Goal | Estudar o fluxo operacional de uma oficina mostrado na demo pública do Torque (pátio de boxes, quadro de serviços, chegadas do dia, técnicos, estoque baixo, carga da oficina) e reconstruir esse comportamento no erp-oficina com **design próprio**, usando o modelo de dados que já existe |
| Requested by | Usuário (dono do erp-oficina) |
| Scope | Tela "Floor" (`#/floor`): KPIs, boxes, quadro de serviços, chegadas, vendas, técnicos, estoque baixo, carga, atividade. Navegação geral só como mapa |
| Out of scope | Código, CSS, ícones, ilustrações, textos e marca do template. Contas, compras e qualquer escrita |
| Clone target market | Brasil, oficinas mecânicas pequenas e médias (as mesmas do erp-oficina) |
| Priorities | 1) Pátio ao vivo por box; 2) quadro por etapa; 3) chegadas do dia; 4) técnicos; 5) estoque baixo |
| Mode | Attended |
| Environment level | L4 (observe only): demo pública com dados fictícios, sem login |
| Write authorization | None |
| KB language | pt-BR |
| Terms of service | O Torque é um template comercial à venda em https://codeandchill.store (a demo mostra "Buy this template"). Não achei a página de licença (`/licence` retornou 404). Decisão do usuário em 2026-10-19: não comprar e fazer **design próprio**. Este estudo registra só comportamento e fluxo, nunca código, CSS, assets ou textos |
